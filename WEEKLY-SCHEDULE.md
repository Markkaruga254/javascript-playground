# Weekly Schedule

## Monday–Friday (8h 20m/day)
- 3h — LeetCode/DSA: problem attempts, review, pattern practice
- 1h 40m — JavaScript: concept study, tracing, implementation, exercises
- 2h 30m — Odin/full-stack project lab: build, debug, test, commit
- 1h 10m — spaced revision, journal, complexity/explanation practice

## Saturday — assessment and practical day (8h 20m)
- Timed DSA assessment and problem review
- JS practical / debugging
- Project checkpoint and self-review
- Weekly scorecard and postmortem

## Sunday — review and recovery
No mandatory full training day. Review the week's mistakes, lightly revise, plan, catch up only on essential backlog, and rest.

## DSA block (3h)
- Problem A: 45m independent attempt
- Problem B: 45m independent attempt
- Problem C: 40m timed attempt
- Problem D or focused pattern drill: 30m
- Review and complexity/reflection: 20m

Daily problem volume is a flexible target, not a reason to rush shallow solutions. Maintain 300 new problems over 16 weeks (~19/week); revision attempts do not count as new.
