# The SWE Residency

## Mission
Become a stronger, independent software engineer in 16 weeks through deliberate practice—not tutorial consumption.

## Commitment
- **50 focused hours/week**
- **16 weeks / 800 hours**
- 6 training days; Sunday review and recovery
- **300 LeetCode target:** 60 Easy, 210 Medium, 30 Hard
- Selected The Odin Project curriculum + practical builds
- Weekly assessment, monthly exam, remediation, and final defense

## Weekly allocation
| Track | Hours |
|---|---:|
| DSA & LeetCode | 20 |
| JavaScript mastery | 10 |
| Full-stack/Odin | 15 |
| Revision, interviews, assessment | 5 |
| **Total** | **50** |

## Standards
1. Attempt before hints.
2. Watching tutorials does not count as completion.
3. Log meaningful progress with Git.
4. Write tests where appropriate.
5. Explain code and complexity in your own words.
6. Record mistakes; revisit weaknesses.
7. Closed-book assessments prohibit AI, notes, hints, and solution lookup.
8. Recovery is part of the program. Sleep and health are not expendable.

## Mastery ladder
- L0 — Not started
- L1 — Studied
- L2 — Practicing with support
- L3 — Independent
- L4 — Mastered: reproduce, explain, analyze, and solve variations
