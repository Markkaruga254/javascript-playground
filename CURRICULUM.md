# 16-Week Curriculum

## Month 1 — Foundations (70 problems)
**Weeks 1–4:** JS declarations, types, conversions, operators, control flow, functions, arrays, strings, objects, array methods, Maps/Sets, scope, recursion, debugging, Big-O.
**DSA:** arrays, strings, hashing, frequency counters, basic sorting, two pointers.
**Build:** Recipes, Landing Page, Rock Paper Scissors, Etch-a-Sketch, Calculator.
**Exam:** 3 Easy + 1 Medium, JS fundamentals, debugging practical, build a small app unaided.

## Month 2 — JavaScript & Frontend (80 problems)
**Weeks 5–8:** DOM, events, event delegation, closures, prototypes, this, OOP, promises, async/await, Fetch, event loop, modules, bundling, testing.
**DSA:** two pointers, sliding window, stacks/queues, binary search, recursion, linked-list introduction.
**Build:** sign-up form, dashboard, library, Tic-Tac-Toe, weather app, restaurant page.
**Exam:** explain closures/scope/async; DOM practical; debug unfamiliar app; 2 Medium + 2 Easy timed.

## Month 3 — Backend & Full Stack (80 problems)
**Weeks 9–12:** Node, npm, filesystem, HTTP, Express, REST, middleware, validation, errors, PostgreSQL, SQL, schema design, auth/authz, testing, security.
**DSA:** linked lists, trees intro, DFS/BFS, intervals, binary search variations, greedy.
**Build:** CLI tool, REST API, DB-backed API, authenticated full-stack milestone.
**Exam:** implement CRUD API with persistence, validation, auth, error handling, and tests; explain request lifecycle.

## Month 4 — Interview & Advanced DSA (70 problems)
**Weeks 13–16:** trees/BST, traversal, graphs, BFS/DFS, heaps, Top K, greedy, intervals, backtracking, dynamic programming, bit manipulation, mixed patterns.
**Build:** full-stack capstone with DB, auth, testing, deployment, docs, security review.
**Final:** two unseen problems, JS practical, debug exercise, project/architecture defense, security, behavioral mock, timed feature implementation, weaknesses remediation.
